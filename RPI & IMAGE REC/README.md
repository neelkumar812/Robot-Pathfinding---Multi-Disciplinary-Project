# CZ3004MDP RPI


- **imageServer.py**: Run on laptop using command line to build image recognition server for task 1.
- **imageServer2.py**: Run on laptop using command line to build image recognition server for task 2.
- **algoServer.py**: Run on laptop using command line or build algo server.
- **task1.py**: Run on RPI after server set up on laptop for task 1.
- **task2.py**: Run on RPI after server set up on laptop for task 2.
- **Main.java**: Algo provided by algorithm team for the run, edited slightly for integration. Refer to algo's submission for full code.

Image recognition is done with yolov5.

- **aloy8.pt**: weights of trained model for task 1.
- **task2.pt**: weights of trained model for task 2.

Host IP address might differ from file to file as I, the main person dealing with RPI was down with COVID for task 2, and teammates had to make adjustments to the code.
